# Exact Pair-Graph Contractions for the Opposite-Spin VBSCF Response

## 1. Purpose and scope

This note records the exact algebraic reordering used to accelerate the
opposite-spin contribution to the matrix-free VBSCF Hessian-vector product.
The optimization is not a cache, screening approximation, low-rank model, or
molecule-specific branch. It changes the contraction order so that the
selected-state coefficient graph is traversed once for each compatible
unique-string pair rather than once for every active-orbital pair channel.

The current implementation applies this reordering to the selected-state
coefficient response, i.e., the part of the outer response generated by

$$
C^{(n)} \longrightarrow C^{(n)} + \delta C^{(n)}.
$$

It covers the directional opposite-spin packed two-electron adjoint and both
spin-sector overlap adjoints. Section 8 distinguishes these completed paths
from the accepted-point and local orbital-response paths that still use tiled
channel contractions.

## 2. Notation

Let $i,j$ denote unique alpha strings, $k,l$ denote unique beta strings, and
$n$ denote a selected electronic state. The selected-state determinant
coefficients are stored as a sparse matrix

$$
C^{(n)} \in \mathbb{R}^{N_\alpha \times N_\beta},
$$

with directional response $\delta C^{(n)}$. The normalized state weight is
$w_n$.

Let $p$ and $q$ denote packed active-orbital pair indices. For one ordered
same-spin string pair, define the sparse first-cofactor projections

$$
A_{ij}^{p}
$$

and

$$
B_{kl}^{q}
$$

for the alpha and beta sectors, respectively. The active-space opposite-spin
pair kernel is

$$
G_{pq}.
$$

For exact active integrals, $G$ is the packed Coulomb kernel. In the
resolution-of-the-identity representation,

$$
G_{pq} = \sum_Q L_{Qp} L_{Qq}.
$$

The derivation below is independent of which exact representation is used to
apply $G$.

## 3. Opposite-spin selected-state functional

For one selected state, the opposite-spin contribution can be written as

$$
E_{\mathrm{os}}^{(n)}
=
\sum_{ij}
\sum_{kl}
\sum_{pq}
C_{ik}^{(n)} C_{jl}^{(n)}
A_{ij}^{p} G_{pq} B_{kl}^{q}.
$$

The state-averaged contribution is

$$
E_{\mathrm{os}}
=
\sum_n w_n E_{\mathrm{os}}^{(n)}.
$$

At a fixed accepted point, the selected-state coefficient response is

$$
\delta E_{\mathrm{os}}^{(C)}
=
\sum_n w_n
\sum_{ij,kl,pq}
\left(
\delta C_{ik}^{(n)} C_{jl}^{(n)}
+
C_{ik}^{(n)} \delta C_{jl}^{(n)}
\right)
A_{ij}^{p} G_{pq} B_{kl}^{q}.
$$

This term is one component of the exact outer response in the matrix-free HVP.

## 4. Directional packed two-electron adjoint

The directional adjoint with respect to the active pair kernel is

$$
\delta \Gamma_{pq}
=
\sum_n w_n
\sum_{ij,kl}
\left(
\delta C_{ik}^{(n)} C_{jl}^{(n)}
+
C_{ik}^{(n)} \delta C_{jl}^{(n)}
\right)
A_{ij}^{p} B_{kl}^{q}.
$$

### 4.1 Channel-major contraction

The previous implementation fixed one beta channel $q$, constructed the sparse
matrix $B^q$, contracted it through the selected-state coefficient matrices,
and repeated that traversal for every $q$. Schematically,

$$
W_{ij}^{q}
=
\sum_n w_n
\sum_{kl}
\left(
\delta C_{ik}^{(n)} C_{jl}^{(n)}
+
C_{ik}^{(n)} \delta C_{jl}^{(n)}
\right)
B_{kl}^{q},
$$

followed by

$$
\delta \Gamma_{pq}
=
\sum_{ij} A_{ij}^{p} W_{ij}^{q}.
$$

Although exact, this order repeats the expensive sparse coefficient-row
products for each of the $P$ active-pair channels.

### 4.2 Pair-major graph contraction

The optimized contraction fixes an ordered alpha string pair $(i,j)$ and first
forms its sparse beta-channel image

$$
y_{ij}^{q}
=
\sum_n w_n
\sum_{kl}
\left(
\delta C_{ik}^{(n)} C_{jl}^{(n)}
+
C_{ik}^{(n)} \delta C_{jl}^{(n)}
\right)
B_{kl}^{q}.
$$

Only determinant connections present in the sparse rows of $C^{(n)}$ and
$\delta C^{(n)}$ are visited. Each visited beta string pair contributes only
the nonzero entries of its sparse projection $B_{kl}^{q}$. The packed adjoint
is then updated through the sparse outer product

$$
\delta \Gamma_{pq}
\mathrel{+}=
A_{ij}^{p} y_{ij}^{q}.
$$

This is an exact reassociation of finite sums:

$$
\sum_q \sum_{kl}
=
\sum_{kl} \sum_{q \in \operatorname{supp}(B_{kl})}.
$$

No matrix element is dropped and no numerical threshold beyond the existing
machine-level sparse-zero convention is introduced.

## 5. Pair-major overlap adjoint

The overlap pullback requires the kernel-projected image

$$
z_{ij}^{p}
=
\sum_q G_{pq} y_{ij}^{q}.
$$

The old implementation first stored or reconstructed $G B_{kl}$ for individual
beta string pairs and then repeated the coefficient contraction for every
target channel $p$. By linearity,

$$
\sum_{kl} \omega_{ij,kl} \left(G B_{kl}\right)
=
G
\left(
\sum_{kl} \omega_{ij,kl} B_{kl}
\right)
=
G y_{ij},
$$

where

$$
\omega_{ij,kl}
=
\sum_n w_n
\left(
\delta C_{ik}^{(n)} C_{jl}^{(n)}
+
C_{ik}^{(n)} \delta C_{jl}^{(n)}
\right).
$$

Therefore the expensive coefficient graph is traversed once, the raw sparse
image $y_{ij}$ is aggregated, and $G$ is applied only after aggregation.

For a regular alpha overlap block $S_{ij}$, let $x_{ij}$ denote its sparse
inverse-overlap packed-pair projection. The scalar determinant weight is

$$
\eta_{ij}
=
x_{ij}^{\mathrm{T}} z_{ij}.
$$

Let $Z_{ij}$ be the occupied-orbital matrix reconstructed from the required
entries of $z_{ij}$. With the internal left/right orientation suppressed for
clarity, the regular determinant overlap pullback has the form

$$
\nabla_{S_{ij}} \Phi
=
\eta_{ij} \det(S_{ij}) S_{ij}^{-\mathrm{T}}
-
\det(S_{ij}) S_{ij}^{-\mathrm{T}}
Z_{ij}
S_{ij}^{-\mathrm{T}}.
$$

Only the following target channels of $z_{ij}$ are required:

$$
\mathcal{T}_{ij}
=
\operatorname{supp}(x_{ij})
\cup
\left\{
\pi(r,s)
\;\middle|\;
r \in \operatorname{occ}_{R}(j),
s \in \operatorname{occ}_{L}(i)
\right\},
$$

where $\pi(r,s)$ is the packed active-pair index. The union is essential. The
support of $x_{ij}$ is sufficient for $\eta_{ij}$ but is not, in general,
sufficient to reconstruct $Z_{ij}$. Using only the first set would lose valid
terms when inverse-overlap elements vanish exactly or cancel under packed-pair
regrouping.

The beta overlap adjoint is obtained by interchanging alpha and beta and using
the sparse transposed coefficient matrices. Both spin sectors use the same
`SelectedStatePairGraph` implementation.

## 6. Complexity and memory

For one selected state, let $d_C(i)$ and $d_{\delta C}(i)$ denote sparse row
degrees in $C$ and $\delta C$, and let $d_B(k,l)$ be the number of nonzero
packed-pair entries in $B_{kl}$. The pair-graph aggregation work is
proportional to

$$
\sum_{ij}
\sum_n
\left[
d_{\delta C^{(n)}}(i) d_{C^{(n)}}(j)
+
d_{C^{(n)}}(i) d_{\delta C^{(n)}}(j)
\right]
\overline{d}_B,
$$

rather than multiplying the coefficient-row traversal by the full number $P$
of active-pair channels.

The packed-adjoint accumulation adds

$$
O\!\left(
\sum_{ij}
d_A(i,j) d_y(i,j)
\right),
$$

where $d_A$ and $d_y$ are actual sparse projection degrees.

For a packed-exact kernel, the targeted overlap projection costs

$$
O\!\left(
\sum_{ij}
\left|\mathcal{T}_{ij}\right|
d_y(i,j)
\right).
$$

For an RI kernel with $N_{\mathrm{aux}}$ auxiliary functions, it costs

$$
O\!\left(
N_{\mathrm{aux}}
\sum_{ij}
\left[
d_y(i,j)
+
\left|\mathcal{T}_{ij}\right|
\right]
\right).
$$

The working storage is one dense vector of length $P$, sparse touched-channel
lists, and the final packed adjoint. No resident object of size
$O(P N_\alpha^2)$ or $O(P N_\beta^2)$ is introduced.

The dense worst case remains important: if every cofactor projection has
degree $P$, the exact kernel application can recover a quadratic dependence on
$P$. A general dense opposite-spin kernel has no universal exact subquadratic
factorization. The observed reduction is therefore a consequence of exploiting
the strict orbital sparsity and determinant compatibility graph already present
in VBSCF, not an unproved dense low-rank assumption.

## 7. Numerical validation

The implementation is checked in three complementary ways:

1. A synthetic nonmatching alpha/beta unique-string test compares the
   pair-graph packed adjoint against the explicit six-index sum.
2. The same test compares both overlap adjoints against direct contraction and
   deliberately uses inverse-projection and occupied-pair target sets that do
   not coincide.
3. Exact finite-difference HVP tests cover both strictly sparse orbitals and
   full-AO OEO orbitals.

For the CERRAS structure-only HVP, the response infinity norm remained

$$
0.292594498619,
$$

while the HVP wall time changed from approximately $93.55$ s to $13.7$--$14.0$
s. The directional opposite-spin backward contribution changed from
approximately $83.32$ s to $3.45$--$3.59$ s. Replacing the accepted-point
adjoints reduced the complete benchmark-process wall time from approximately
$87.31$ s to $43.07$ s and peak resident memory from approximately $6.55$ GB
to $6.20$ GB; no swap was used. The difference between process and HVP wall
times is accepted-point construction and teardown outside the timed HVP.

For the full-AO FeCl2 test, the complete structure-only HVP required
approximately $0.157$ s, of which approximately $0.051$ s was the
opposite-spin directional backward contribution.

## 8. Implementation coverage

The phrase "pair-graph rewrite" should be used only for paths that traverse
selected-state coefficient connectivity before active-pair channels.

| Opposite-spin path | Current method | Pair-graph rewrite |
|---|---|---|
| Directional selected-state packed adjoint | `SelectedStatePairGraph` plus sparse projection outer products | Complete |
| Directional selected-state alpha overlap adjoint | Pair graph, aggregate-then-apply kernel, targeted output | Complete |
| Directional selected-state beta overlap adjoint | Transposed pair graph, aggregate-then-apply kernel, targeted output | Complete |
| Accepted-point packed adjoint | `SelectedStatePairGraph` plus sparse projection outer products | Complete |
| Accepted-point alpha/beta overlap adjoints | Pair graph, aggregate-then-apply kernel, targeted output | Complete |
| Local orbital/integral response packed adjoint | Accepted and directional pair-payload tiles | Not yet rewritten |
| Local orbital/integral response overlap adjoints | Directional projected-image tiles | Not yet rewritten |
| Forward structure H/S action | Unique-string channel factorization with streamed block action | Already factorized, but not this pair-graph algorithm |
| Directional structure-response action | Sparse channel-major accepted and directional projections | Not yet rewritten with this algorithm |
| Determinant-pair scalar evaluator | Sparse projection dot product | Pair-local operation; this rewrite is not applicable |
| Same-spin pair-cache construction | Per-spin cofactor and inverse projections | Producer of graph payloads; this rewrite is not applicable |

The completed paths include both accepted-state and directional-state global
coefficient contractions. The most plausible next use of the same principle is
the local orbital/integral response, but it requires a generalized graph
carrying $\delta A$, $\delta B$, and $\delta G$ payloads. It should not be
implemented as a mechanical substitution because its derivative structure is
different from the pure $\delta C$ response derived above.
